# Chelnok Boxing Timer

A professional boxing timer app for fighters and coaches. Chelnok is the most polished round timer on mobile, designed for serious boxing training.

## Features

- ⏱️ **Quick Timer Setup** - Start timing in seconds with preset configurations
- 🥊 **Boxing Presets** - Pre-configured rounds for Boxing 3x3, Boxing 5x3, Muay Thai 5x3, and custom workouts
- 🔊 **Audio Announcements** - Clear voice and sound alerts for round transitions, prep phase, and work/rest intervals
- 📊 **Session History** - Track all completed workouts with date, duration, and rounds completed
- 🎨 **Dark Premium Design** - Large, readable display optimized for gym use with gloves
- 🌙 **Keep Screen Awake** - Screen stays on during workouts
- 📱 **Vibration Feedback** - Customizable haptic feedback for round changes
- 🌍 **Multi-Language Support** - English, Russian, and Czech localizations
- ⚙️ **Customizable Settings** - Theme, language, sound, vibration, and screen wake preferences

## Get Started

1. Launch the app - goes straight to timer screen
2. Tap presets or customize your own workout
3. Hit START and train
4. View your session history anytime

## Requirements

- Android 6.0+ (API 21+)
- Permission: VIBRATE, POST_NOTIFICATIONS, WAKE_LOCK

## About

Chelnok helps fighters get better training sessions with less thinking. Start clean in seconds, focus on the workout, track progress over time.
